| F-05 | `1b135b6a4de7250730c4cbd21dfc936b.png` | 单击自动详情遮挡图库；透明大图仍露出详情，沉浸感不足 |

实施时不得依赖聊天临时绝对路径；上表中的问题描述和本文档的验收条件是权威依据。

### 2.2 用户给出的影响优先级

最终优先级为：

1. **A：真正连续、无周期空洞的瀑布流。**
2. **B：单击、沉浸大图与详情侧栏的交互重构。**
3. **F：间距、圆角和边框外观控制。**
4. **E：PureRef 式透明纯图片模式。**
5. **C：收录后的快速人工分类与编辑。**
6. **D：输入文字上下裁切。**

实施顺序严格沿用该优先级；共享基础样式可以在相关步骤中准备，但不得以“顺手修改”为由提前完成后续父步骤。

### 2.3 已定位的直接原因

1. 当前 `GalleryLayoutEngine.CreateWaterfallRows` 使用 `WaterfallSectionDepth = 4`，每处理 `columnCount * 4` 张图片就重置列高度。
2. 每个虚拟化分段的高度由该段最高列决定，其他较短列在分段底部留下周期性空洞。
3. `MainWindow.Selection.cs` 中选择路径会调用 `InspectItem`，因此第一次单击就打开检查器；第二次单击才触发沉浸大图。
4. 当前检查器是 `MainWindow.xaml` 中宽 380 DIP 的右侧覆盖浮层，不占用布局宽度，所以会挡住后方图片。
5. 当前 `App.xaml` 的全局 `TextBox` 模板把 `PART_ContentHost` 按 `VerticalContentAlignment` 垂直居中，同时多个输入框使用固定高度和内边距，150% 缩放时容易裁切字形。
6. `InspectorTagsEditor` 当前固定 `Height="40"`，不适合两至三行标签。
7. 收录完整编辑器已有提示词、备注、分类和标签，但 `CaptureCapsuleWindow` 必须先点“展开”才能进入。
8. AI 当前产生 `description`、`category`、`tags`、`style`、`lighting`、`color`、`composition`、`texture`、`atmosphere`；`notes` 是独立的用户字段，不是 AI 字段。

## 3. M7 权威产品决策

本节覆盖总蓝图中与 M7 新反馈冲突的旧交互描述。M0–M6 的历史完成记录保持不变。

### 3.1 瀑布流

- 每张图片必须进入当前累计高度最短的列。
- 不要求同一水平线严格保持从左到右时间顺序。
- 保持完整原始比例，允许裤子图、全身图特别长，也允许超宽图特别矮。
- 不允许通过裁切、强行统一高度或周期性列对齐伪装瀑布流。
- 图库自然结束时各列底部不齐属于正确结果，不算空洞。
- 列数根据可用宽度和目标图片宽度自动计算，适应 Photoshop 上方的小窗口。

### 3.2 单击、沉浸大图和详情

- 单击：只选择图片。
- 方向键：只移动选择，不自动打开详情。
- 双击或空格：进入纯图片沉浸大图。
- `Q`：普通模式打开或关闭详情侧栏。
- 右键菜单和普通模式悬停按钮：增加“查看详情”。
- 详情打开后跟随当前选择更新内容。
- 详情关闭后不清除选择。
- 详情采用主窗口内部右侧占位侧栏，不做独立可移动浮窗。
- 侧栏默认约 440 DIP，可拖动 360–720 DIP，记忆宽度。
- 打开或关闭侧栏允许发生一次重排，但必须保持当前图片和视口锚点。

### 3.3 详情保存

- 分类、标签、备注在离开输入框或切换图片前自动保存。
- 一次自动保存以分类、标签、备注的事务快照为单位。
- 自动保存后显示约 10 秒“已保存 · 撤销”。
- 撤销恢复该事务保存前的分类、标签和备注。
- 新的自动保存可以替换当前 Toast；只承诺撤销最近一次自动保存。
- 提示词仍必须点击“保存提示词”。
- 未保存提示词时切换图片，显示“保存 / 放弃 / 留在当前图片”。
- 标签编辑器自动扩展到两至三行，超过三行后内部滚动。

### 3.4 宽高比与 AI 审美属性

- 详情新增宽高比，不移除 AI 审美属性。
- 示例格式：`2:3 · 0.667 · 竖图`。
- 继续显示原始像素尺寸，例如 `830 × 1245 px`。
- 比例由原始宽高计算，不依赖 AI。

### 3.5 外观

- 顶部增加“外观”弹出面板。
- 可实时调整横向间距、纵向间距、圆角、边框粗细和边框颜色。
- 默认横向间距 8 DIP、纵向间距 8 DIP、圆角 12 DIP、边框 0 DIP。
- 建议范围：间距 0–32 DIP、圆角 0–32 DIP、边框 0–4 DIP。
- 外观设置全局保存；布局模式和目标图片宽度继续按主图库/外部来源分别记忆。
- 提供“恢复默认”。

### 3.6 透明模式

- 透明模式是 PureRef 式纯图片层。
- 默认隐藏检查器、文件名、状态栏、普通按钮和卡片悬停按钮。
- 只有顶边和左边缘可以唤出必要控制。
- 暂不增加鼠标穿透开关。
- 透明模式按 `Q` 不打开详情，也不自动退出；只提示“请先退出透明模式查看详情”。
- 进入透明模式时关闭详情显示，但保留当前选择。
- 退出透明模式后不自动重开详情；需要用户再次按 `Q`。
- 选中轮廓保持克制，约 1 DIP，并在约 1 秒后淡出；新的选择或方向键操作会短暂恢复。

### 3.7 快速标注

- 提供可记忆开关，在“快速标注”和当前安静胶囊模式之间切换。
- 快速标注模式允许主动获取焦点；安静模式不得抢走 Photoshop 或浏览器焦点。
- 字段顺序：主分类 → 标签 → 备注 → 提示词。
- 显著入口：`上衣参考`、`裤子参考`、`其他 / 交给 AI`、`更多分类`。
- 快捷键：`1` 上衣参考、`2` 裤子参考、`0` 其他/交给 AI。
- `Ctrl+Enter` 完成本次收录。
- `Esc` 或 × 立即取消本次收录，不保留 10 秒撤销。
- 取消只清理 PromptVault 为本次捕获创建的暂存副本，不影响源文件或剪贴板来源。
- 取消后再次复制同一图片必须可以重新触发收录。
- `其他 / 交给 AI` 不是数据库中的真实分类。
- 如果不存在 `上衣参考`、`裤子参考`，快速标注功能自动以完全相同的名称安全创建。

### 3.8 人工字段与 AI 权威

- 任何人工分类，包括“更多分类”选择，都不能被 AI 覆盖。
- 人工标签非空时，AI 不生成或保留标签草稿。
- 人工备注非空时，把备注视为人工描述，AI 不生成或保留 `description` 草稿。
- AI 永远不能写入或覆盖 `notes`。
- AI 仍可生成风格、光影、色彩、构图、材质和氛围属性。
- 清空人工字段不会自动启动 AI，只有主动“重新分析”才重新生成。
- `其他 / 交给 AI` 不写入分类；AI 分类保持候选状态，用户确认后才成为主分类。
- 手动选择 `上衣参考` 或 `裤子参考` 后，重新分析也不得改变主分类。

### 3.9 无提示词收录矩阵

| 人工分类 | 提示词 | 结果 |
| --- | --- | --- |
| 上衣参考 / 裤子参考 / 更多分类 | 有或无 | 允许立即保存；人工分类为权威 |
| 其他 / 交给 AI | 有 | 保存为未分类，进入 AI 分类候选流程 |
| 其他 / 交给 AI | 无 | 保留在待补提示词流程；不创建名为“其他”的分类 |
| 未选择任何操作 | 无 | 保留在待补提示词流程 |

如果未来希望“无提示词且交给 AI”也立即进入图库，需要单独改变本表并评估捕获状态机和 AI Job 对暂存图片的支持；M7 不静默扩大该语义。

## 5. 不可回退的技术与数据安全边界

### 5.1 性能和画面连续性

- 不回退 M1 的数据分页和 UI 虚拟化。
- 不为 30,000 项预创建全部 WPF 卡片或 ViewModel。
- 不移除 480/720/1080/1600px 缩略图档位。
- 不回退高运动期间暂停新图片提交的保护。
- 不回退旧图库保持到新首屏就绪的协议。
- `RowsList.Opacity` 或后继图库表面必须始终保持 1；禁止用整层淡入掩盖加载。
- 不允许整层全黑或近黑帧。
- 不静默降低总蓝图第 10 节性能标准。
- 如果真正连续瀑布流必须引入自定义 `VirtualizingPanel`，先用隔离原型证明可见元素数和帧时间，再替换正式布局。

### 5.2 真界面隔离

所有真界面验证必须：

1. 显式传入 `--settings <工作区内测试设置文件>`。
2. `LibraryRoot` 指向工作区或临时目录中的合成图库。
3. `CaptureListeningEnabled=false`。
4. 在线 AI 关闭，凭据写入为 0。
5. 不添加真实外部文件夹。
6. 不打开、迁移、写入或删除真实图库。
7. 如果需要验证收录，只在单独隔离会话中临时开启监听，并只把合成图片和合成文本写入剪贴板。
8. 清理临时目录前解析并核对绝对路径确实位于工作区或专用临时根目录。

### 5.3 数据与设置迁移

- 外观和侧栏宽度优先存入设置文件，不为纯界面偏好修改数据库 schema。
- 如果旧设置只有单一 `Spacing`，迁移时把旧值同时用于横向和纵向间距，不能丢失用户偏好。

## 8. 推荐验证命令与隔离要求

在仓库根目录设置本地运行目录：

```powershell
$env:APPDATA=(Resolve-Path '.').Path+'\.appdata'
$env:LOCALAPPDATA=(Resolve-Path '.').Path+'\.localappdata'
$env:DOTNET_CLI_HOME=(Resolve-Path '.').Path+'\.dotnethome'
$env:NUGET_PACKAGES=(Resolve-Path '.').Path+'\.packages'
```

构建与测试必须顺序运行，避免共享 `obj` 目录竞争：

```powershell
& '.\.dotnet\dotnet.exe' build src\PromptVault.App\PromptVault.App.csproj -c Debug --no-restore
& '.\.dotnet\dotnet.exe' test tests\PromptVault.Tests\PromptVault.Tests.csproj -c Debug --no-restore
```

统一性能门禁使用现有 M6 脚本；实施时先完整阅读脚本参数，不猜测：

```powershell
powershell -ExecutionPolicy Bypass -File tools\release\Invoke-M6Gate.ps1
```

真界面启动必须使用显式设置：

```powershell
& '.\.dotnet\dotnet.exe' run --project src\PromptVault.App\PromptVault.App.csproj -- --settings '<工作区内合成设置 JSON>'
```

如果使用最终 EXE，同样显式传入：

```powershell
& '<最终隔离发布目录>\PromptVault.exe' --settings '<工作区内合成设置 JSON>'
```

禁止：

- 只设置 `LOCALAPPDATA` 就假定图库已隔离。
- 使用真实图库做 UI 烟测。
- 开着真实剪贴板收录进行自动化。
- 把本机绝对路径写入提交的 JSON 或 Markdown。
- 为追求截图效果关闭虚拟化或降低性能门槛。
