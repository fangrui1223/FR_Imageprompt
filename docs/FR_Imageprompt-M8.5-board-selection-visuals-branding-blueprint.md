## 0. 已确认的产品契约

1. 未选中的画板图片不显示边框；图片现有圆角裁切、内容、位置、尺寸和旋转保持不变。
2. 单选一张图片时，图片自身仍不显示边框，只显示共同变换层的一圈极细选中框和四角手柄。
3. 多选图片时，每张被选图片保留独立极细蓝色边框，同时显示共同变换外框和四角手柄，便于辨认离散选择成员与整体变换范围。
4. 普通选择轮廓以接近一个显示器物理像素为目标；画布缩放和 Windows DPI 改变时不得跟随变粗。
5. 固定相框裁剪继续使用现有 2 DIP 橙色外框，不纳入普通选择线宽补偿，不改变裁剪输入、渲染、保存或撤销协议。
6. 便签选择、图片/便签缩放、Shift/Alt 变换、右键职责、数据库结构和 M7.2 图库性能层均不改变。
7. 主界面标题 `FR_Imageprompt` 不变；其下蓝色小字保持现有颜色、字号和位置，只把文字替换为 `图片资产库 V2.0`，不带括号。

## 1. 根因与实现原则

- 当前每张图片的根 `Border` 固定使用 2 DIP 边框；被选中时只替换颜色，因此未选中图片也有常驻边框，缩小后边框相对图片显得更粗。
- 选中图片时，根 `Border` 与屏幕空间共同选择框同时绘制，单选形成重复轮廓，多选时共同外框跨过成员间空白。
- 图片根元素位于画布世界空间，会随 `_viewport.Zoom` 缩放；逐图选择线必须按 `1 / (Zoom × DpiScale)` 计算世界厚度，才接近一个物理像素。
- 共同选择框位于屏幕空间，不受画布矩阵缩放；其普通线宽按 `1 / DpiScale` DIP 计算。
- 所有线宽策略必须集中为可单元测试的纯逻辑，不把魔法数字分散到事件处理器。
