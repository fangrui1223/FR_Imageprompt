# FR_Imageprompt V2.0 完整操作说明

> 适用版本：FR_Imageprompt V2.x（含 M9 离线许可证版本）  
> 更新日期：2026-08-30  
> 适用系统：Windows 10/11 x64  
> 本手册列出当前正式界面对用户开放的全部键盘快捷键和主要鼠标手势；仅供开发诊断使用的隐藏测试快捷键不列入日常操作。

---

## 1. 软件用途

FR_Imageprompt 是一款本地图片资产、提示词和灵感画板管理工具，主要用于：

- 从浏览器、资源管理器或截图工具快速收录图片；
- 保存提示词、主分类、标签、备注和 AI 草稿；
- 用瀑布流或等高布局浏览大量图片；
- 搜索、筛选、收藏、回收和恢复图片；
- 在沉浸大图中查看图片；
- 使用 PureRef 式自由画板摆放、缩放、裁剪、旋转和分组参考图；
- 使用本地 AI 生成可人工校正的分类、标签、描述与审美属性。

图片、提示词、分类、画板和数据库默认保存在你选择的本地图库中。在线 AI 默认关闭；本地 AI 不上传图片。

## 2. 安装、授权与首次启动

### 2.1 解压运行

1. 解压 `FR_Imageprompt-M9-licensed-win-x64.zip`。
2. 打开解压后的文件夹。
3. 双击 `FR_Imageprompt.exe`。
4. 软件为自带运行环境的单文件程序，不需要另外安装 .NET。

建议把程序放在固定目录，不要直接在 ZIP 压缩包内部运行。

### 2.2 第一次授权

第一次运行会出现“需要许可证”窗口：

1. 点击“复制请求码”。
2. 把形如 `FR2-xxxxx-...` 的请求码发给授权人。
3. 收到 `.frlicense` 文件后，点击“导入许可证…”。
4. 选择许可证文件。
5. 验证通过后，软件会在当前进程继续启动，不需要联网或重启。

设备请求码是本机标识的单向摘要，不包含图片、提示词、图库路径、用户名、账号或网络信息。

许可证绑定电脑，不绑定程序目录或图库：

- 移动程序、重新解压或更新任意 V2.x 版本不需要重新授权；
- 更换图库不需要重新授权；
- Windows 重装、系统盘更换或设备请求码变化时，需要重新签发；
- 一年许可证到期后需要续签；
- V2 许可证不自动授权未来 V3；
- 不要编辑 `.frlicense` 内容，任何修改都会导致签名失效。

### 2.3 选择图库

授权通过后，第一次进入程序需要选择图库文件夹。

可以选择：

- 一个新的空文件夹；
- 以前已经由 FR_Imageprompt 创建的图库文件夹。

图库内常见内容包括：

- `promptvault.db`：图片资料、分类、标签、画板等数据库；
- `originals`：受管原图；
- `thumbnails`：缩略图；
- `backups`：升级与恢复备份。

不要手工删除或修改 `promptvault.db`、`backups`、`originals` 或 `thumbnails`。需要搬迁图库时，应先完全退出软件，再整体复制图库文件夹。

## 3. 主界面认识

### 3.1 顶部菜单

顶部菜单默认自动隐藏。把鼠标停在窗口顶边约 90～140ms 即可显示。主要功能包括：

- 搜索提示词或备注；
- 标签筛选；
- 最新/最旧排序；
- 开关剪贴板收录监听；
- 切换安静收录与快速标注；
- 进入透明模式；
- 调整边缘菜单灵敏度；
- 调整图片外观；
- 让顶部和左侧菜单常显；
- 多选、删除、回收站；
- 窗口置顶、最小化、最大化和关闭。

### 3.2 左侧菜单

把鼠标停在窗口左边缘可显示左侧菜单。主要功能包括：

- 查看全部图片或按分类浏览；
- 浏览外部文件夹；
- 新建分类；
- 添加外部文件夹；
- 导入本地 AI 模型包；
- 打开 AI 设置；
- 导出诊断包；
- 打开图库文件夹。

### 3.3 图库区域

图库支持两种布局：

- 瀑布流：图片保持原始比例，每张进入当前最短列；
- 等高拼接：同一行高度接近，横向排列。

“密度”和“尺寸”控制图片大小，“外观”控制：

- 横向间距；
- 纵向间距；
- 图片圆角；
- 边框粗细；
- 边框颜色。

默认值为横纵间距 8 DIP、圆角 12 DIP、边框 0。

## 4. 收录图片

### 4.1 开关收录监听

顶部“收录监听：开/关”控制是否监听剪贴板。

- 开：复制图片或图片文件时会触发收录；
- 关：复制操作不会进入 FR_Imageprompt。

在 Photoshop、浏览器等软件中大量复制但不希望收录时，可以临时关闭。

### 4.2 支持的收录方法

可以通过以下方式收录：

- 在浏览器中复制图片；
- 在资源管理器中复制图片文件；
- 使用截图工具把截图放入剪贴板；
- 把 PNG、JPEG、WebP、BMP 或 GIF 文件拖入主界面。

重复图片按解码后的像素哈希识别，不会无声创建完全相同的重复记录。

### 4.3 安静收录模式

适合连续收集图片和提示词，不打断 Photoshop 或浏览器操作：

1. 顶部选择“收录：安静”。
2. 复制图片。
3. 右下角出现不抢焦点的小提示。
4. 接着复制提示词文本。
5. 文本稳定约 600ms 后自动关联保存。
6. 需要补分类、标签或备注时，点击提示中的“展开”。

两分钟内没有提示词的图片会进入“待补提示词”，不会被删除。

### 4.4 快速标注模式

适合每张图片都要单独选择主分类：

1. 顶部选择“收录：快速”。
2. 复制图片。
3. 快速标注窗口出现。
4. 依次填写主分类、标签、备注和提示词。
5. 保存或取消。

快速标注快捷键：

| 快捷键 | 作用 | 注意 |
| --- | --- | --- |
| `1` 或数字键盘 `1` | 选择“上衣参考” | 光标正在文字输入框中时不会触发 |
| `2` 或数字键盘 `2` | 选择“裤子参考” | 光标正在文字输入框中时不会触发 |
| `0` 或数字键盘 `0` | 选择“其他 / 交给 AI” | 这不是一个真实分类 |
| `Ctrl+Enter` | 保存本次收录 | 没有提示词但已手工分类时也可保存 |
| `Esc` | 立即取消本次收录 | 暂存图片立即清理，无 10 秒撤销 |

人工分类、标签和备注优先于 AI：

- 人工选择“上衣参考”或“裤子参考”后，AI 不会覆盖主分类；
- 人工填写标签后，AI 不再生成标签草稿；
- 人工填写备注后，AI 不再生成描述草稿；
- AI 仍可生成审美属性草稿。

## 5. 浏览、选择与复制

### 5.1 鼠标选择

| 操作 | 作用 |
| --- | --- |
| 单击图片 | 只选择图片，不打开详情 |
| `Ctrl+单击` | 增加或取消某一张选择 |
| `Shift+单击` | 从选择锚点到当前图片进行连续范围选择 |
| `Ctrl+Shift+单击` | 在已有选择基础上追加一个连续范围 |
| 双击图片 | 打开沉浸大图 |
| 鼠标中键单击图片 | 直接复制这一张的提示词 |
| 右键图片 | 打开“查看详情 / 移到回收站”等菜单 |
| 悬停图片 | 显示分类、标签及详情、复制、收藏、画板按钮 |

### 5.2 键盘选择

先单击图库空白或任意图片，让键盘焦点位于图库。

| 快捷键 | 作用 |
| --- | --- |
| `←` / `→` / `↑` / `↓` | 按当前瀑布流实际位置移动选择 |
| `Home` | 选择当前结果中的第一张 |
| `End` | 选择当前结果中的最后一张 |
| `Shift+方向键` | 扩展连续选择 |
| `Ctrl+Shift+方向键` | 在已有选择基础上追加连续范围 |
| `Ctrl+C` | 复制所有选中图片的非空提示词 |
| `Space` | 打开当前选中图片的沉浸大图 |
| `Q` | 打开或关闭右侧详情 |
| `Esc` | 详情打开时关闭详情 |

注意：主图库中的 `Ctrl+C` 复制提示词文本；画板中的 `Ctrl+C` 复制原图文件，含义不同。

### 5.3 收藏

把鼠标移到图片上，点击星形按钮即可收藏或取消收藏。也可以打开 `Ctrl+K` 命令面板，执行“筛选：只看收藏”。

## 6. 搜索、筛选与命令面板

### 6.1 即时搜索

按 `Ctrl+F` 聚焦顶部搜索框。可搜索提示词和备注中的中文或英文片段。

搜索框快捷键：

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+F` | 显示顶部菜单、聚焦搜索框并全选现有文字 |
| `↓` | 保留搜索内容，把焦点交给图库并选中首个结果 |
| `Enter` | 与 `↓` 相同，进入图库结果 |
| `Esc` | 保留搜索内容，只把焦点返回图库 |

搜索过程中旧图片会继续显示，首屏新结果准备好后一次替换，不会主动清空成黑场。

### 6.2 标签与分类

- 在顶部“标签筛选”中输入一个或多个标签；
- 从左侧“图库分类”选择分类；
- 点击左侧顶部的全部图片可清除分类；
- 使用命令面板可以更快地搜索分类、标签和来源。

### 6.3 命令面板

按 `Ctrl+K` 打开命令面板。可以输入命令、分类、标签或外部来源名称。

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+K` | 打开或关闭命令面板 |
| `↑` / `↓` | 移动命令选择 |
| `Enter` | 执行选中的命令 |
| `Esc` | 关闭命令面板并返回图库 |
| 双击命令 | 直接执行 |

命令面板可执行搜索、清除筛选、收藏筛选、分类、标签、来源、布局、密度、详情、沉浸大图、画板、外观、收录模式、透明模式、AI 和诊断导出等操作。

## 7. 图片详情与元数据编辑

### 7.1 打开详情

有三种方法：

- 选择图片后按 `Q`；
- 悬停图片，点击“详情”；
- 右键图片，选择“查看详情”。

详情侧栏会占用右侧真实宽度，使图库进行一次正常重排，不会盖在图片上。拖动侧栏左侧分隔条可调整宽度，软件会记住设置。

详情打开后会跟随图库选择。方向键只移动选择，不会额外打开新窗口。

### 7.2 保存规则

- 主分类、标签和备注：离开输入框或切换图片前自动保存；
- 自动保存后约 10 秒内可点击“撤销”；
- 提示词：必须点击“保存提示词”；
- 提示词未保存就切换图片：选择“保存 / 放弃 / 留在当前图片”；
- 按 `Esc` 或再次按 `Q`：关闭详情。

详情中还会显示：

- 原图尺寸和格式；
- 约分宽高比、小数比例和横竖方向；
- AI 草稿；
- 来源；
- 风格、光影、色彩、构图、质感和氛围等审美属性。

## 8. 沉浸大图

打开方法：

- 双击图片；
- 选择图片后按 `Space`。

大图快捷键与鼠标：

| 操作 | 作用 |
| --- | --- |
| `←` | 上一张 |
| `→` | 下一张 |
| 鼠标侧键“后退” | 上一张 |
| 鼠标侧键“前进” | 下一张 |
| 鼠标滚轮 | 放大或缩小，范围约 1～10 倍 |
| 放大后按住左键拖动 | 平移图片 |
| `0` 或数字键盘 `0` | 恢复 100% 和居中位置 |
| `Esc` | 退出沉浸大图 |

点击画面左右边缘也可切换上一张或下一张。

## 9. 透明模式

按 `Ctrl+M` 切换普通模式与透明模式。

透明模式用于在 Photoshop 等软件上方只看图片：

- 默认隐藏顶部栏、左侧栏、详情、标题、状态文字和悬停按钮；
- 隐藏的界面仍保留原布局占位，切换透明前后图片大小、列数、屏幕位置、滚动锚点和选择不变；
- 把鼠标移到顶边或左边缘可临时呼出控制；
- 图片选择细框约 1 秒后淡出，但选择不会丢失；
- 按 `Q` 不会打开详情，只提示先退出透明模式；
- 双击或 `Space` 仍可进入沉浸大图；
- `Ctrl+鼠标右键拖动` 可移动整个主窗口。

透明模式切换本身不会重新装载图库或重排图片。程序会先在不可见的新窗口中恢复当前行、滚动锚点和虚拟化画面，连续稳定两帧后再与旧窗口原子交接，因此即使已向下浏览，也不会闪回首屏。只有实际拖动窗口边缘改变尺寸时，才会在改窗结束后防抖执行一次正常重排。

本版没有鼠标穿透开关。

## 10. 外部文件夹

左侧点击“＋ 添加文件夹”，可把现有图片目录作为外部来源浏览。

外部文件夹特点：

- 只建立索引，不复制或修改外部原文件；
- 首次扫描和后续增量更新在后台完成；
- 文件消失时显示不可用，不会删除其他文件；
- 外部图片可以拖出到其他软件；
- 收藏到主图库后，才会进入 FR_Imageprompt 的受管存储。

外部来源快捷键：

| 快捷键 | 作用 |
| --- | --- |
| `Alt+M` | 把当前选中的外部图片收藏到主图库 |

## 11. 回收站

### 11.1 移入回收站

可以：

- 右键图片选择“移到回收站”；
- 多选后点击顶部“删除选中”。

这一步不是永久删除。

### 11.2 恢复

1. 点击顶部“回收站”。
2. 选择一张或多张图片。
3. 点击“恢复选中”，或右键选择“从回收站恢复”。

### 11.3 永久删除

在回收站中右键图片，选择永久删除，并完成确认。永久删除不可撤销，会删除数据库记录及受管文件；操作前确认图片确实不再需要。

## 12. AI 草稿与审核

### 12.1 本地 AI

导入兼容模型包后，本地 AI 可以生成：

- 描述；
- 分类建议；
- 标签建议；
- 风格、光影、色彩、构图、质感和氛围；
- 相似图片向量。

AI 结果先进入草稿，不会覆盖人工确认的数据。

### 12.2 在线 AI

在线 AI 默认关闭。需要时从左侧“AI 设置”启用并配置密钥。密钥进入 Windows 凭据管理器，不应写入提示词、备注或项目文件。

### 12.3 AI 待校正快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Enter` | 确认当前草稿或保存修改后的值 |
| `Ctrl+R` | 拒绝当前草稿 |
| `Alt+←` | 上一条草稿 |
| `Alt+→` | 下一条草稿 |

## 13. 自由画板入门

### 13.1 打开画板

可通过以下方式：

- 主界面按 `Ctrl+Shift+F`，打开或激活最近使用的画板；
- 悬停图库图片点击“画板”；
- 详情侧栏点击“加入画板”；
- `Ctrl+K` 搜索画板命令。

画板顶部栏默认隐藏。把鼠标停在画板顶部 8 DIP 感应区约 250ms，或按 `Alt+Q`，即可显示；再次按 `Alt+Q` 可立即隐藏。鼠标离开顶部栏及其安全通道约 500ms 后自动隐藏。

### 13.2 新建与管理画板

从顶部栏或画布空白处右键菜单可以：

- 新建画板；
- 切换画板；
- 重命名当前画板；
- 删除当前画板；
- 改变画板背景；
- 新建便签；
- 打开属性；
- 切换窗口置顶。

删除画板只删除画板和其中的引用，不删除主图库原图。

## 14. 画板浏览与窗口控制

### 14.1 缩放和平移画布

| 操作 | 作用 |
| --- | --- |
| 鼠标滚轮 | 以鼠标位置为中心缩放画布 |
| 按住鼠标中键拖动 | 平移画布内容 |
| `Alt+鼠标左键拖动`空白处 | 平移画布内容 |
| 按住普通鼠标右键拖动 | 平移画布内容 |
| 短按鼠标右键 | 打开当前位置对应的右键菜单 |
| `Ctrl+鼠标右键拖动` | 移动整个画板窗口，不改变画布相机 |
| `Ctrl+0` | 把画布缩放恢复到 100%，并居中当前选择、全部内容或空画布原点 |
| `Ctrl+Space` | 适合并显示完整画板 |
| `Esc` | 在临时相机中恢复第一次进入前的原缩放和位置 |

画板最大化时，`Ctrl+右键拖动`会先在指针附近还原窗口，再继续移动。

### 14.2 聚焦

| 快捷键或操作 | 作用 |
| --- | --- |
| `Space` | 有选择时立即聚焦当前选择；无选择时优先恢复临时相机，否则在最近一次手工平移/缩放前后视野之间切换 |
| `Ctrl+Space` | 无论当前选择如何，都立即适合完整画板 |
| `Ctrl+0` | 立即切到 100%；有选择居中选择，无选择居中全部内容，空画板居中原点 |
| `Esc` | 退出临时相机并恢复第一次进入前的缩放和位置 |
| 双击图片 | 立即聚焦该图片；再次双击同一目标恢复；改为双击另一张时不覆盖最初快照 |
| 聚焦单图时 `←` / `→` | 切换相邻图片并保持聚焦 |

在便签文字编辑状态下，`Space` 正常输入空格，不会触发画板聚焦。
如果当前正在“完整画板”或其他不同目标的临时视图中，有选择时第一次 `Space` 会立即改为聚焦当前选择；再次按 `Space` 才恢复最初保存的缩放和位置。活动画板会优先处理 `Ctrl+Space`，避免被 Windows 输入法组合键吞掉；切换到其他窗口后不会继续占用该热键。

### 14.3 顶部栏、属性和置顶

| 快捷键 | 作用 |
| --- | --- |
| `Alt+Q` | 立即显示或隐藏画板顶部栏 |
| `I` | 打开或关闭临时属性面板 |
| `Ctrl+Shift+A` | 切换画板窗口置顶 |

属性面板覆盖在画布右侧，不压缩或重新排列画板内容。

## 15. 画板选择、移动、缩放与旋转

### 15.1 选择

| 操作 | 作用 |
| --- | --- |
| 单击图片 | 选择该图片；同组图片会按组选择 |
| `Shift+单击图片` | 增加或取消选择 |
| 空白处按住左键拖框 | 框选图片和便签 |
| `Shift+空白拖框` | 在原选择基础上追加框选 |
| `Ctrl+A` | 选择画板中的全部图片和便签 |
| 单击空白 | 清除选择 |
| `Esc` | 依次取消便签编辑、取消裁剪、恢复临时相机、关闭属性或清除选择；不会关闭画板 |

### 15.2 移动

- 选中图片后，直接按住图片左键拖动；
- 多选时拖动任意已选图片或共同选择框，会整体移动；
- 便签未在编辑时可从节点内部拖动；双击文字区域才进入编辑。

### 15.3 图片和多选缩放

选中图片后，使用四个角上的圆形手柄：

| 操作 | 作用 |
| --- | --- |
| 直接拖角 | 保持图片比例缩放 |
| `Shift+拖角` | 自由改变宽度和高度，可拉伸变形 |
| `Alt+拖角` | 从中心保持比例缩放 |
| `Shift+Alt+拖角` | 从中心自由改变宽度和高度 |

右键图片选择“变换 > 重置尺寸”，可恢复推荐尺寸。

### 15.4 便签缩放

- 选中便签只显示一个右下角抓手；拖动抓手只改变框宽高，不改变字号；
- 便签最小为 32×24 DIP；背景关闭时仍保留同一矩形命中区域；
- 文字不会自动换行或自动补高，超出框的部分会裁切；需要时右键选择“适合文字内容”一次调整；
- 右键菜单可编辑、适合内容、开关背景、调整对齐、应用五个预设、复制、层级或删除；
- 单选便签后按 `I` 打开临时属性，可调字号 8–300、行距 1.0–10.0、左/中/右对齐、文字色，以及背景开关、颜色、透明度、圆角和上下边距；文字色与背景色按钮保留可读文字和独立色块，点击后使用内置常用色或输入 `#RRGGBB`，实时预览但只在关闭/Enter 时保存一次，Esc 回滚；
- 多选便签可以一起移动、缩放、删除、调整层级或批量应用预设，但属性面板只编辑单个便签。

### 15.5 旋转

| 操作 | 作用 |
| --- | --- |
| `Ctrl+鼠标左键拖动图片` | 连续旋转选中图片 |
| `Ctrl+Shift+鼠标左键拖动图片` | 以 15° 为单位吸附旋转 |
| 右键“变换 > 左转 5° / 右转 5°” | 精细旋转 |
| 右键“变换 > 重置旋转” | 恢复 0° |

### 15.6 层级与分组

右键图片或使用属性面板可以：

- 移到最前；
- 前移一层；
- 后移一层；
- 移到最后；
- 组合所选；
- 取消分组；
- 重命名所在分组。

## 16. 画板裁剪模式

裁剪只改变画板里的显示区域，不修改原图文件。

进入方法：

1. 只选择一张图片。
2. 在图片上短按鼠标右键。
3. 打开“裁剪”子菜单。
4. 选择“裁剪模式”。
5. 选择框变成橙色。

裁剪操作：

| 操作 | 作用 |
| --- | --- |
| 图片框内滚轮 | 在固定相框内放大或缩小图片 |
| 图片框内按住左键拖动 | 调整图片在相框内的位置 |
| `Enter` | 完成裁剪 |
| 框内双击 | 完成裁剪 |
| 点击框外 | 完成裁剪 |
| `Esc` | 取消本次裁剪并恢复进入前状态 |
| 裁剪中短按右键 | 显示完成、取消和重置裁剪菜单 |

裁剪过程中，框外的画布不会被滚轮误缩放；裁剪完成时只保存一次。

## 17. 画板复制、便签、撤销与删除

| 快捷键 | 作用 | 说明 |
| --- | --- | --- |
| `Ctrl+C` | 复制选中图片的原图文件 | 与主图库“复制提示词”不同 |
| `Ctrl+V` | 粘贴 FR_Imageprompt 受管图片引用 | 普通外部图片不会直接作为画板引用导入 |

| `Enter` | 编辑当前单选便签 | 进入时自动全选旧文字 |
| `Ctrl+Enter` | 保存当前便签文字 | 点击外部也会保存 |
| `Ctrl+D` | 复制所选便签 | 复制内容、尺寸和样式 |

双击便签也可进入编辑；`Esc` 取消本次文字修改。五个样式预设保存在应用设置中：左键应用，右键确认后用当前样式覆盖对应槽位；预设不包含文字、位置、尺寸或层级。属性滑块只实时更新当前便签视觉，松手时才保存一次。连续拖动、缩放、旋转、裁剪或属性滑动只在手势完成后写入一次数据库和一条撤销记录。

## 19. 诊断、备份与故障处理

### 19.1 导出诊断包

从左侧菜单或 `Ctrl+K` 命令面板选择“导出诊断包”。诊断包只包含：

- 最近 14 天的脱敏日志；
- 应用、.NET、Windows 和架构版本；
- 数据库大小和脱敏升级状态。

不会包含图片、完整提示词、设置文件、API 密钥或许可证私钥。发送前仍建议用压缩软件检查一次内容。

### 19.2 备份建议

- 定期整体备份图库文件夹；
- 升级前保留图库副本；
- 不要只备份 `originals` 而遗漏 `promptvault.db`；
- 不要在程序运行时用同步工具同时覆盖数据库；
- 许可证文件不在图库内，重装 Windows 前应保留原许可证，但请求码变化后仍可能需要重签。

### 19.3 常见问题

#### 软件只显示“需要许可证”

检查许可证是否已导入、是否属于当前电脑、是否过期。不要修改许可证文件。Windows 重装或系统盘变化后，把新请求码交给授权人。

#### 复制图片没有反应

检查顶部“收录监听”是否开启；再确认剪贴板中确实是图片或图片文件，而不是网页链接文字。

#### 图片进入“待补提示词”

表示图片已经安全暂存，但两分钟内没有收到提示词。稍后进入待补入口补写，不需要重新收录图片。

#### 外部图片无法直接在画板使用

外部文件夹只做只读索引。先用 `Alt+M` 或右键把图片收藏到主图库，再加入画板。

#### 画板右键没有弹出菜单

右键发生拖动时会被解释为平移画布。保持鼠标不移动，短按并松开右键即可弹出菜单。

#### 画板拖角变成拉伸

普通拖角应保持比例；按住 `Shift` 才会自由拉伸。检查 Shift 键是否卡住或被其他软件占用。

#### 误删图片

如果只是“移到回收站”，进入回收站恢复；如果已经在回收站执行永久删除，则无法从软件撤销，应从图库备份恢复。

## 20. 授权人签发器附录

`FR_LicenseManager.exe` 只供授权人保留，不能放进普通用户软件包。

### 20.1 签发许可证

1. 打开 `FR_LicenseManager.exe`。
2. 确认顶部显示“V2 签发私钥已就绪，与当前 FR_Imageprompt 公钥匹配”。
3. 输入使用人名称。
4. 粘贴收件人发来的设备请求码。
5. 选择“永久（默认）”或“一年”。
6. 点击“生成许可证…”。
7. 保存 `.frlicense` 文件并发送给对应使用人。

一份许可证只适用于请求码对应的电脑。把同一许可证和程序复制给另一台电脑，另一台电脑仍无法进入。

### 20.2 备份签发私钥

首次正式发证前必须：

1. 点击“备份签发密钥…”。
2. 设置至少 10 个字符的强口令。
3. 保存 `.frauthority` 文件。
4. 把备份文件和口令分开保存，最好各保留两个离线副本。

私钥丢失不会让已签发许可证失效，但会导致以后无法继续签发。不要生成另一把密钥替代现有 V2 私钥，否则旧程序不会承认新签发的许可证。

### 20.3 恢复签发私钥

1. 打开签发器。
2. 点击“恢复签发密钥…”。
3. 选择 `.frauthority` 备份。
4. 输入备份口令。
5. 确认状态恢复为“与当前 FR_Imageprompt 公钥匹配”。

签发私钥保存在授权人 Windows 凭据管理器中，不在程序目录、源码仓库或用户许可证文件中。
