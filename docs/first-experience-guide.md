# FR_Imageprompt 2.0 首次体验与问题反馈指南

这份说明用于第一次体验完成 M7.1 P0 滚动与虚拟化回归修复的 2.0.0 体验包。建议预留 30–45 分钟，先使用一个全新的测试图库完成一轮，再决定是否打开真实图库。

## 1. 体验前准备

准备以下内容：

- 6–12 张不含隐私信息的测试图片，最好同时包含人物、场景、产品、插画和横竖图；
- 3–5 段中英文提示词；
- 一个新的空文件夹，作为“体验图库”；
- 可选的本地模型包 `PromptVault-CLIP-ViT-B32-pants-reference.zip`。

首次体验请不要选择正在使用的真实图库。剪贴板监听开启后，应用会收录你复制的图片，因此测试期间不要复制私人截图、密码二维码或其他敏感内容；暂时不用收录时，点击顶部的“收录监听：开”将其关闭。

正式候选包位于：

`publish/FR_Imageprompt-M7.1-P0-win-x64.zip`

它是免安装、自带运行时的 Windows x64 单文件版本。程序尚未代码签名；如果 Windows 显示来源或信誉提醒，请先确认压缩包来自本仓库，并核对 SHA-256：

`49499174ceddae49ef9884b3a055177ea698f48b516fbb22b600cae2d4c632ba`

## 2. 第一次启动

1. 把 ZIP 完整解压到一个普通文件夹，不要直接在压缩包内运行。
2. 双击 `PromptVault.exe`。
3. 首次运行时选择刚才准备的空“体验图库”文件夹。
4. 主界面出现后，把鼠标停在窗口顶边或左边约 0.1 秒，确认顶部菜单和左侧菜单能够滑出。
5. 确认顶部能看到“收录监听：开/关”“收录：安静/快速”和“外观”，左侧能看到“添加文件夹”“导入 AI 模型包”“AI 设置”和“导出诊断包”。

预期结果：启动过程中没有数据库、迁移或恢复错误；主界面能够正常最大化、缩放和调整大小。

关闭主窗口后程序会按设计留在系统托盘。需要完全退出时，右键托盘图标并选择“退出”。

## 3. 体验自动收录

### 完整图片和提示词

1. 确认“收录监听”为开启状态。
2. 在浏览器中复制一张图片，或在资源管理器中复制一个图片文件。
3. 先使用“收录：安静”，观察右下角是否出现不抢焦点的收录胶囊。
4. 接着复制一段提示词。
5. 等待约 600ms，观察胶囊状态及主图库中新出现的卡片。
6. 单击新卡片确认只出现克制的选择轮廓；按 `Q` 打开右侧详情，核对原图、提示词和来源信息。

预期结果：复制内容时当前窗口焦点不被抢走；图片和提示词只生成一条记录；卡片和检查器均能正常预览。

### 快速人工标注

1. 把顶部切换为“收录：快速”，再复制一张只用于测试的服装参考图。
2. 编辑器出现后按 `1` 选择“上衣参考”，或按 `2` 选择“裤子参考”；也可以点“更多分类”。
3. 分类已经人工确定时，即使没有提示词也可按 `Ctrl+Enter` 保存。
4. 再复制一张测试图，按 `0` 选择“其他 / 交给 AI”，确认它不是一个真实分类。
5. 再复制一张图后按 `Esc` 取消，然后重新复制同一张图，确认能够再次触发。
6. 体验结束后切回“收录：安静”，不用收录时关闭监听。

预期结果：快速模式只在你明确打开时获取焦点；上衣/裤子人工分类不会被 AI 覆盖；取消立即生效且没有撤销入口。

### 重复图片

再次复制同一张图片和另一段提示词。预期不会悄悄生成多条完全重复记录，而是按像素内容识别已有图片并更新相应信息。

### 待补提示词

1. 再复制一张测试图片，但不要复制提示词。
2. 等待两分钟，确认它进入“待补提示词”。
3. 打开待补收件箱，补充提示词并保存。
4. 完全退出并重新启动一次，确认已保存项目仍在。

如果不想等待两分钟，可以先跳过这一项，之后再单独检查。

## 4. 体验主图库

依次检查以下操作：

1. 按 `Ctrl+F` 聚焦搜索，分别输入中文和英文片段。
2. 快速连续修改搜索词，确认旧画面会保留到新结果出现，而不是闪成黑场。
3. 切换瀑布流和等高布局，调整密度、排序、分类及标签筛选。混合横图、竖图、细长图时，瀑布流应持续填入最短列且不出现周期性空洞。
4. 按住并拖动右侧滚动条滑块，确认图库在拖动过程中实时跟随；用 `Home`、`End`、`PageUp`、`PageDown` 和快速往返滚动检查，不应出现局部列空白或整屏空白。
5. 如果标题显示“已加载 240”，继续滚动接近底部；程序会自动追加下一批。全部加载后标题只显示图库总数。
6. 单击、`Ctrl` 单击和 `Shift` 单击测试单选、多选及连续选择。
7. 按方向键、`Home`、`End` 和 `Shift` + 方向键测试键盘导航。
8. 按 `Ctrl+C` 复制选中图片的提示词。
9. 单击图片确认只选择；用方向键移动选择确认不会自动开详情。
10. 按 `Q`、卡片悬停“详情”和右键“查看详情”分别打开右侧占位式详情。拖动分隔条，确认图库只重排一次且侧栏不盖住图片。
11. 双击图片或按空格进入沉浸大图，使用 `←`、`→`、`0` 和 `Esc`。
12. 点击顶部“外观”，分别调整横/纵间距、圆角和边框，再恢复默认 8/8/12/0。
13. 按 `Ctrl+K`，搜索“布局”“外观”“画板”“相似”“诊断”等命令并执行。
14. 按 `Ctrl+M` 切换透明模式。确认默认只保留图片、悬停不显示卡片按钮，`Q` 只提示先退出；双击大图后不应透出详情。随后切回普通模式。

重点观察：滚动是否跟手、缩略图是否错位、搜索是否跳动、菜单是否难以唤出、检查器是否遮挡内容，以及切换时是否出现黑场。

## 5. 编辑、回收站与外部文件夹

### 编辑元数据

在右侧详情修改分类、用户标签和备注，离开输入框或切图，确认它们自动保存并出现约 10 秒“已保存 · 撤销”。提示词仍需点击“保存提示词”；编辑后直接切图时，应出现“保存 / 放弃 / 留在当前图片”。确认宽高比同时显示约分、小数和横竖方向，AI 审美属性仍然存在。

### 回收站

右键一张测试图片并选择“移到回收站”，随后打开回收站检查恢复流程。只用测试图片操作；不要手工删除体验图库中的 `promptvault.db`、`originals` 或 `backups`。

### 外部文件夹

1. 在左侧选择“添加文件夹”，指定一个只含测试图片的文件夹。
2. 等待后台索引完成，浏览和搜索这些外部图片。
3. 在资源管理器中新增、改名或移走一张测试图片，观察应用稍后是否同步。
4. 对当前外部图片使用右键菜单或 `Alt+M`，确认它能收藏到主图库。

外部文件夹浏览只建立索引，不应修改或删除源文件；收藏时才会复制图片到主图库。

## 6. 体验本地 AI 与相似图片

本步骤可选。没有模型包时，收录、搜索、标签和画板仍应正常工作。

1. 在左侧点击“导入 AI 模型包”。
2. 选择 `artifacts/PromptVault-CLIP-ViT-B32-pants-reference.zip`。
3. 导入成功后，再收录一张新的测试图片，以触发后台本地分析。
4. 等待右侧检查器出现 AI 草稿、来源、置信度或审美属性。
5. 分别体验“确认 AI”“拒绝”和“待校正”窗口。
6. 对已经生成向量的图片执行“相似图片”命令。

预期结果：AI 结果先作为草稿出现，不会覆盖手工保存的数据；确认、修改或拒绝后状态能够保存。本地模型不会上传图片。

首次体验建议保持“在线 AI”关闭。只有你明确配置自己的 HTTPS 服务并接受图片上传时，再单独测试在线分析。

## 7. 体验自由画板

1. 从图库卡片、右侧检查器或 `Ctrl+K` 把两至三张图片加入画板。
2. 新建并重命名一个画板。
3. 测试拖动、缩放、旋转、裁剪、层级和分组。
4. 添加便签并切换画板背景。
5. 使用 `Ctrl+Z`、`Ctrl+Y`、`Ctrl+A` 和 `Delete`。
6. 关闭画板并重新打开，随后完全退出应用再启动，确认布局、便签和视口仍能恢复。

删除画板或画板项目只应删除布局引用，不应删除图库原图。

## 8. 完成一轮体验后的检查

一轮体验结束时，建议确认：

- 重启后图库数量、搜索、标签、待补项目和画板仍正常；
- 主界面关闭后托盘行为符合预期；
- 不使用收录时已经关闭剪贴板监听；
- 体验图库中的 `backups` 目录存在；
- 没有意外创建重复图片或丢失提示词；
- 没有持续占用大量 CPU、显存或内存；
- 4K、150% 缩放下没有文字裁切、按钮重叠或窗口越界。

## 9. 发现问题后如何反馈

先记下问题发生的大致时间，然后从左侧菜单或 `Ctrl+K` 选择“导出诊断包”。诊断 ZIP 不包含图片、完整提示词、设置文件或 API 密钥，但发送前仍建议自行打开检查。

每个问题尽量按下面格式单独记录：

```text
问题标题：
严重程度：阻塞 / 明显影响 / 轻微体验
发生位置：
发生时间：
显示器分辨率和缩放：

复现步骤：
1.
2.
3.

预期结果：
实际结果：
复现概率：每次 / 偶尔 / 仅一次

是否使用测试图库：
是否开启剪贴板监听：
是否导入本地模型：
是否开启在线 AI：

附件：截图或录屏、诊断包文件名
```

如果应用启动失败，请保留整个体验图库，不要删除数据库或备份。记录错误弹窗内容及日志位置后再反馈。
