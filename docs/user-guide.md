# FR_Imageprompt 2.0 用户指南

## 1. 主图库

顶部菜单包含搜索、标签筛选、排序、收录开关、透明模式、边缘灵敏度、多选和回收站。菜单默认隐藏，把指针移到窗口顶边短暂停留即可显示；左侧分类和外部文件夹菜单使用相同方式从左边缘唤出。若不喜欢自动隐藏，可把“边栏”切换为常显。

搜索输入有约 90ms 防抖，查询期间继续显示旧结果，首屏准备好后一次替换，不会主动清空成黑场。中文和英文都支持片段匹配。布局、密度和每个来源的偏好会保存到设置中。

单击卡片会选中并打开右侧检查器。`Ctrl` 单击切换多选，`Shift` 单击或 `Shift` + 方向键选择连续范围。`Ctrl+C` 复制所有选中项的非空提示词；鼠标中键可直接复制单张提示词。空格或双击进入大图，左右键切图，`0` 复位缩放，`Esc` 退出。

## 2. 收录与待补收件箱

剪贴板监听支持浏览器位图、截图和资源管理器图片文件。图片进入独立暂存区并先生成预览，不会因为提示词迟到而丢失：

1. 复制图片后右下角显示非抢焦点胶囊。
2. 随后复制文本，文本稳定约 600ms 后保存。
3. 胶囊中的“展开”可补分类、标签和备注。
4. 保存后 10 秒内可以撤销。
5. 两分钟没有提示词时进入“待补提示词”；重启后仍可恢复。

重复图片按解码像素 SHA-256 识别，再次收录会更新原记录，不会无声生成重复项。混合图片/文件事件会合并同一剪贴板序列，但不同图片仍分别保留。

## 3. 外部文件夹

“添加文件夹”只建立持久索引，不复制或修改源文件。扫描、文件监控和低频复检在后台进行。外部图片可拖出；右键或 `Alt+M` 会复制到主图库并进入正式管理。若源文件消失，索引会显示不可用，不会删除其他文件。

## 4. AI 草稿与相似图片

本地模型生成描述、分类、标签、风格、光影、色彩、构图、质感和氛围候选。它们先进入“待校正”，不会覆盖用户已经确认或手工编辑的字段。检查器会显示来源、模型版本和置信度。

AI 审核窗口支持逐条确认、修改、拒绝和前后导航。AI 作业存入 SQLite 队列；进程异常退出时，未完成作业在下次启动重新排队或达到重试上限后明确失败。

相似图片使用本地 CLIP 向量；文本找图只接受模型包中允许的词汇组合。没有模型包时，收录、搜索、标签和画板照常工作。

## 5. 自由画板

从卡片菜单、检查器或 `Ctrl+K` 打开/加入画板。画板支持：

- 多个命名画板，新建、重命名、切换和删除；
- 从图库多选拖入，或把图片文件拖入画板；
- 平移、缩放、旋转、裁剪、层级、分组、便签和四种背景；
- `Ctrl+A` 全选，`Ctrl+Z` / `Ctrl+Y` 撤销/重做，`Delete` 删除；
- 缺失原图仍保留位置、尺寸和路径快照，可手工重新定位。

每次完成拖放、缩放、裁剪或便签编辑后立即写入 SQLite；视口也会延迟保存并在关闭时再保存一次。SQLite 事务保证进程崩溃时保留上一次完整提交。

## 6. 诊断与支持

左侧菜单或命令面板选择“导出诊断包”。ZIP 只包含：

- 最近 14 天的脱敏 JSONL 日志；
- 应用、.NET、操作系统和架构版本；
- 数据库文件大小和脱敏后的升级阶段状态。

不会收集用户图片、完整提示词、设置文件、API 密钥或任意环境变量。导出后可用压缩工具再次人工检查。
