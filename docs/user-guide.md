# FR_Imageprompt 2.0 用户指南

## 1. 主图库

顶部菜单包含搜索、标签筛选、排序、收录开关、快速/安静收录模式、透明模式、边缘灵敏度、外观、多选和回收站。菜单默认隐藏，把指针移到窗口顶边短暂停留即可显示；左侧分类和外部文件夹菜单使用相同方式从左边缘唤出。若不喜欢自动隐藏，可把“边栏”切换为常显。

搜索输入有约 90ms 防抖，查询期间继续显示旧结果，首屏准备好后一次替换，不会主动清空成黑场。中文和英文都支持片段匹配。瀑布流采用连续最短列：每张图片进入当前最短列并完整保留原始比例，不再按固定分段对齐。布局、密度和每个来源的偏好会保存到设置中。

单击卡片只选择图片，不会自动弹出详情。`Ctrl` 单击切换多选，`Shift` 单击或 `Shift` + 方向键选择连续范围；方向键只移动选择。按 `Q`、卡片悬停“详情”或右键“查看详情”可打开右侧占位式侧栏，侧栏会压窄图库而不是覆盖图片，分隔条可拖动并记住宽度。`Ctrl+C` 复制所有选中项的非空提示词；鼠标中键可直接复制单张提示词。空格或双击进入纯图片大图，左右键切图，`0` 复位缩放，`Esc` 退出。

详情中的分类、标签和备注会在离开输入框或切换图片前自动保存，并在约 10 秒内提供撤销。提示词仍需点击“保存提示词”；有未保存提示词时切图会询问保存、放弃或留在当前图片。详情同时显示约分比例、小数比例和横竖方向，例如 `2:3 · 0.667 · 竖图`，不会移除 AI 审美属性。

顶部“外观”可分别调整横向间距、纵向间距、圆角、边框粗细和边框颜色并实时预览。圆角直接裁切图片四角，边框为 0 时仍然有效；边框会沿相同的圆角轮廓绘制。默认横/纵间距均为 8 DIP、圆角 12 DIP、边框 0；可一键恢复默认。

透明模式是 PureRef 式纯图片层：默认隐藏详情、文件名、状态栏、卡片文字和悬停按钮，只从顶边或左边缘唤出控制。选中轮廓约 1 秒后淡出，但选择仍保留。透明模式下 `Q` 只提示先退出，不会打开详情；双击或空格仍进入不透出后层 UI 的沉浸大图。

## 2. 收录与待补收件箱

剪贴板监听支持浏览器位图、截图和资源管理器图片文件。图片进入独立暂存区并先生成预览，不会因为提示词迟到而丢失：

收录有两个可记忆模式：

- 安静模式：复制图片后右下角显示不抢焦点的胶囊。随后复制文本，文本稳定约 600ms 后保存；“展开”可以补分类、标签和备注。
- 快速模式：复制图片后打开紧凑编辑器，字段顺序是分类、标签、备注、提示词。按 `1` 选择“上衣参考”，`2` 选择“裤子参考”，`0` 选择“其他 / 交给 AI”，也可从“更多分类”选已有分类；`Ctrl+Enter` 保存，`Esc` 或 × 立即取消本次收录。

若图库还没有“上衣参考”“裤子参考”，第一次使用时会幂等创建。人工分类、标签和备注优先于 AI，模型不会覆盖；“其他 / 交给 AI”不是实际分类。已经人工选择上衣或裤子后，即使没有提示词也可以保存。交给 AI 但没有提示词时继续进入“待补提示词”，两分钟超时与重启恢复行为不变。取消会立即清理本次暂存，没有 10 秒撤销；再次复制同一张图片仍可重新触发。

重复图片按解码像素 SHA-256 识别，再次收录会更新原记录，不会无声生成重复项。混合图片/文件事件会合并同一剪贴板序列，但不同图片仍分别保留。

## 3. 外部文件夹

“添加文件夹”只建立持久索引，不复制或修改源文件。扫描、文件监控和低频复检在后台进行。外部图片可拖出；右键或 `Alt+M` 会复制到主图库并进入正式管理。若源文件消失，索引会显示不可用，不会删除其他文件。

## 4. AI 草稿与相似图片

本地模型生成描述、分类、标签、风格、光影、色彩、构图、质感和氛围候选。它们先进入“待校正”。人工分类存在时不再生成分类候选；人工标签存在时不再生成标签候选；人工备注存在时不再生成描述候选。风格、光影、色彩、构图、质感和氛围仍可生成。确认 AI 分类时只映射到已有分类，无法映射就保留候选等待人工选择。

AI 审核窗口支持逐条确认、修改、拒绝和前后导航。AI 作业存入 SQLite 队列；进程异常退出时，未完成作业在下次启动重新排队或达到重试上限后明确失败。

相似图片使用本地 CLIP 向量；文本找图只接受模型包中允许的词汇组合。没有模型包时，收录、搜索、标签和画板照常工作。

## 5. 自由画板

从卡片菜单、检查器或 `Ctrl+K` 打开/加入画板。画板采用 PureRef 式“内容优先”界面：默认不显示固定工具栏和检查器，把指针停在顶边约 90–140ms，或按 `F10` / `Alt`，才会出现覆盖式顶部栏；离开后自动隐藏，不会压缩画布。

最常用操作：

- 多个命名画板，新建、重命名、切换和删除；
- 从图库单选或多选加入画板；外部文件需要先收录到图库；
- 滚轮以指针为锚缩放，中键拖动或 `Alt`+左键拖动平移，空白左键拖动框选，`Shift` 增减选择；
- 单击只选择；同组任一图片会按组整体选择。`Space` 聚焦所选内容，无选择时适合完整画板，再按一次精确回到原相机；`Ctrl+Space` 始终适合完整画板；单图聚焦时 `←` / `→` 切换相邻图片；双击图片聚焦，再双击同一目标恢复；
- 四角拖动默认等比缩放，`Shift` 解锁宽高，`Alt` 从中心缩放，`Shift+Alt` 从中心自由变形；多选使用共同外框并保持相对布局；`Ctrl`+对象拖动连续旋转，加入 `Shift` 后按 15° 吸附；
- 右键空白、图片或便签打开各自的紧凑命令菜单。窗口化时右键拖动移动窗口，最大化时右键拖动平移画布，松手不会误弹菜单；
- 按 `I` 打开临时属性检查器，它覆盖在画布右侧而不压缩或重排内容；按 `I`、`Esc`、关闭按钮或点击空白关闭；
- 顶部栏“置顶”、`Ctrl+Shift+A` 和右键“窗口置顶”是同一个可记忆开关；
- `Ctrl+A` 全选，`Ctrl+Z` / `Ctrl+Y` 撤销/重做，`Delete` 删除；
- 缺失原图仍保留位置、尺寸和路径快照，可手工重新定位。

`Space` 的含义取决于当前窗口：主图库中是打开沉浸大图；自由画板中是聚焦/恢复，不再用于平移。编辑便签时 Space 仍正常输入文字，不触发聚焦。

画板图片先保留当前预览，相机立即运动；停稳后才按显示物理像素渐进升级高清。快速切换会取消旧请求，失败或原图缺失不会把当前图片清空。每次完成拖放、缩放、旋转、裁剪或便签编辑后才写入 SQLite；连续手势中不反复写库，并只产生一条撤销记录。视口延迟保存并在关闭时再保存一次。

## 6. 诊断与支持

左侧菜单或命令面板选择“导出诊断包”。ZIP 只包含：

- 最近 14 天的脱敏 JSONL 日志；
- 应用、.NET、操作系统和架构版本；
- 数据库文件大小和脱敏后的升级阶段状态。

不会收集用户图片、完整提示词、设置文件、API 密钥或任意环境变量。导出后可用压缩工具再次人工检查。
