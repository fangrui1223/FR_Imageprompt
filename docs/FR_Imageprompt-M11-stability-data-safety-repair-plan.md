## 1. 范围、决策与交付标准

1. 修复重复收录陈旧快照、撤销覆盖后续编辑、升级失败回滚与回收站清理顺序、下载流生命周期、异常设置恢复。
2. 复用现有收录开关：单张图片保持正常处理；剪贴板一次多个文件或文件夹整次忽略，不提示、不进收件箱、不退回位图/文本分支。显式拖入、手工导入不受此规则影响。
3. 修复画板 50 步历史上限、保存失败假成功与未保存内容保护、透明窗口重复交接/交接期间状态连续性、主图库高 DPI 整窗拖动。
4. 撤销收录若检测到之后的人工或其他内容修改，保留当前内容并说明冲突；不自动覆盖或删除。尽量利用既有持久状态完成原子校验，不为实现方便随意升级 schema。
5. 图片/便签保存失败要保留明确的待保存状态，允许重试。切换、关闭、裁剪完成和撤销恢复必须遵循实际写入结果；不以短暂提示代替恢复路径。
6. 本轮不增加参考锁定、多图排版、在线服务或新许可证流程，不改变模型分类、画板基础快捷键或既有 UI 布局。
7. 交付修复源码、针对性回归测试、原始验证结果、完整执行账本和新的普通用户 ZIP；完成修复提交与远端核对。

## 2. 不得回退的契约

- 不打开、迁移、删除或重建真实图库；所有故障注入使用唯一合成目录。测试设置显式关闭收录监听、快速编辑和在线 AI。不得读取签发私钥或将许可证/图库/设置打入用户包。
- 保留 SQLite WAL、FTS、受管文件一致性和迁移备份恢复；写入参数化，失败不能用清空有效数据兜底。
- 保留 M7.2 分规模缓存、虚拟化、旧图保持和大图库完整可达，不恢复 240 张上限或全量位图常驻。
- 透明切换继续隐藏预热、两帧稳定和原子交接，切换零重排、图片尺寸和滚动锚点不变；透明手工改窗继续 180ms 防抖一次重排。
- 画板保留四角 28 DIP 输入所有权、固定对角线投影、绝对指针位移和选择快照；手势中不重建图片视觉/位图、不写数据库，完成一次提交。
- 保留固定相框裁剪、Space/Ctrl+Space/Ctrl+0/Esc 共用首次临时视图、Alt+Q 顶栏和 DPI 补偿细轮廓；便签样式继续使用现有兼容载荷，不扩展富文本或 schema。
