## 0. 新对话接手摘要

### 0.1 已确认产品方向

- 不需要迁就现有画板操作习惯；以最终体验质量为准。
- 学习 PureRef 的精髓，但不机械复制其全部键位、菜单或文件格式。
- 正常状态下只显示图片、便签和克制的选择反馈，不保留固定顶部工具栏、固定右侧检查器或底部状态栏。
- `Space` 只负责聚焦与恢复，不再兼任“按住空格拖动画布”。
- 没有选中内容时，`Space` 让整个画板内容充满窗口；选中内容时让所选区域充满窗口；再次按下精确恢复进入前的视野。
- `Ctrl+Space` 无视当前选择，始终显示完整画板。
- 滚轮缩放画布，中键或 `Alt+左键`平移画布，左键用于选择、移动和框选。
- 主要功能进入上下文右键菜单；右键短按打开菜单，右键拖动按窗口状态移动窗口或平移画布。
- 顶部栏默认隐藏，只在顶边意图停留、键盘命令或明确设置下出现。
- 顶部栏必须包含“窗口置顶”按钮；该按钮控制画板窗口 `Topmost`，不是把顶部栏固定显示。
- 右侧检查器改为临时浮层，按 `I` 或右键“属性”出现，不压缩画布。
- 图片默认保持比例缩放；`Shift` 才允许自由宽高变换，`Alt` 从中心缩放，旋转和裁剪保持独立语义。
- 放大聚焦时立即使用已有图片完成视野切换，再异步无闪烁升级高清，不允许等待高清后才显示。
- 本阶段不加入自由绘制、箭头、矩形标注、画板导出或跨画板复制；命令目标设计应避免阻塞未来增加新画板对象。

### 0.2 PureRef 官方交互参考

只使用 PureRef 官方手册作为交互事实来源：

- 导航、极简界面、右键菜单、标题栏显隐、平移和缩放：`https://www.pureref.com/handbook/navigation/`
- 图片选择、缩放、裁剪和 `Space` 聚焦/恢复：`https://www.pureref.com/handbook/images/`
- `Ctrl+Space` 聚焦完整画布：`https://www.pureref.com/handbook/canvas/`
- 默认快捷键和命令名称：`https://www.pureref.com/handbook/shortcuts/all-shortcuts/`

M8 的差异化决定：

- PureRef 默认以 `Space` 聚焦所选、`Ctrl+Space` 聚焦画布；M8 在无选择时把 `Space`自然扩展为聚焦全部内容，以减少空操作。
- PureRef 的快捷键可高度自定义；M8 第一版先提供固定且可发现的稳定键位，不在本阶段实现完整快捷键编辑器。
- PureRef 能处理独立场景文件；M8 继续使用当前 SQLite 画板和图库资产引用，不引入新的场景文件格式。

### 0.3 建档时已确认的当前实现

- `src/PromptVault.App/BoardWindow.xaml` 为 151 行，固定顶部工具栏、320 DIP 右侧检查器和 30 DIP 底部状态栏参与窗口布局。
- `src/PromptVault.App/BoardWindow.xaml.cs` 为 1,396 行，缩放、平移、选择、拖动、缩放、裁剪、分组、便签、历史和窗口管理集中在一个 code-behind。
- 当前滚轮使用鼠标位置为中心缩放，缩放范围由 `BoardViewportEngine` 固定为 `0.1–8.0`。
- 当前 `Space` 只设置 `_spacePressed`，配合左键平移；没有聚焦会话或恢复视野。
- 当前“适合”计算所有图片和便签的轴对齐矩形，不支持只适合选择，也没有计算旋转后的真实外包围盒。
- 当前图片右下角单个 `Thumb` 分别修改宽高；没有保持比例、多选共同外框或从中心缩放。
- 当前双击图片用于重新定位缺失源图，必须迁移为聚焦；重新定位保留在右键菜单和临时检查器。
- 当前画板没有上下文右键菜单、命令模型、隐藏式顶部栏、无边框窗口或置顶偏好。
- 现有画板数据模型已经保存位置、尺寸、层级、旋转、四边裁剪、分组、便签和视口；M8 核心交互不需要重建画板数据库。
- M5 的 5,000 项合成门禁：301 次可见区查询 P50 `0.0502ms`、P95 `0.0558ms`、最大 `1.1776ms`，最多 108 个可见候选。
- M7.2.1 建档基线的 Debug/Release 测试为 227/227，M7.2 三规模门禁为 11/11；M8-00 必须重新运行，不能直接把这些历史数字当成 M8 验收结果。

## 2. M8 权威交互契约

### 2.1 画布相机

| 操作 | 结果 |
| --- | --- |
| 滚轮 | 以指针所在世界坐标为锚点缩放画布 |
| 中键拖动 | 平移画布 |
| `Alt+左键`拖动空白 | 平移画布 |
| `Space`，有选择 | 聚焦全部所选内容 |
| `Space`，无选择 | 聚焦完整画板，包含图片与便签 |
| 再次 `Space` | 精确恢复进入聚焦前的相机 |
| 双击图片 | 与选中该图片后按 `Space` 相同 |
| `Ctrl+Space` | 始终聚焦完整画板，不改变选择 |
| `Ctrl+0` | 恢复 100% 缩放，以当前视口中心为锚点 |
| 聚焦单图时 `←` / `→` | 按稳定加入顺序聚焦上一张/下一张 |

聚焦规则：

- 聚焦前只保存一个工作相机快照：OffsetX、OffsetY、Zoom 和当时视口尺寸。
- 聚焦中切换图片、调整窗口大小或继续缩放，不覆盖工作相机快照。
- 再次 `Space`、双击同一目标或 `Esc` 退出聚焦时，恢复原工作相机。
- 关闭窗口、切换画板或保存视口时，不能把临时聚焦相机写入 `boards`；保存进入聚焦前的工作相机。
- 聚焦边界使用旋转后的真实外包围盒；多选使用所有选择对象边界的并集。
- 聚焦留白采用视口短边约 6%，并限制在 32–96 DIP；极小对象仍受 `MaximumZoom` 限制。
- 过渡目标为约 120–160ms；启用减少动效时立即完成，不播放装饰性动画。
- 动画期间收到新缩放、平移或聚焦命令时，从当前矩阵继续，不先跳回旧状态。
- 便签文本框正在编辑时，`Space` 必须输入空格，不能触发全局聚焦。

### 2.2 选择、框选和对象移动

| 操作 | 结果 |
| --- | --- |
| 左键单击图片/便签 | 只选择该对象 |
| `Shift+左键` | 增减连续多选 |
| 左键拖动空白 | 生成选择矩形 |
| `Shift+框选` | 把命中对象加入当前选择 |
| 单击空白 | 清除选择 |
| 拖动已选对象 | 移动全部所选对象 |
| `Esc` | 按“编辑模式→聚焦→浮层→选择”的顺序退出 |
| `Ctrl+A` | 选择当前画板全部可交互对象 |
| `Delete` | 只从画板移除或删除便签，不删除图库图片 |

选择轮廓：

- 默认 1 DIP 克制描边，缩放画布时保持近似屏幕恒定粗细。
- 缩放手柄视觉尺寸约 8 DIP，但透明命中区不小于 18 DIP。
- 未选择、正在聚焦或鼠标远离时不显示常驻按钮。
- 分组内任一图片被普通单击时继续选择整组；进入组内编辑属于后续能力，不在 M8 扩展层级模型。

### 2.3 图片变换

| 操作 | 结果 |
| --- | --- |
| 拖动四角 | 保持当前可见内容比例缩放 |
| `Shift+拖角` | 解锁宽高比例，自由变形 |
| `Alt+拖角` | 从中心缩放 |
| `Shift+Alt+拖角` | 从中心自由变形 |
| `Ctrl+左键拖动`所选对象 | 围绕对象中心连续旋转 |
| `Ctrl+Shift+左键拖动` | 旋转吸附到 15° |
| 多选共同外框拖角 | 连同对象间距、位置和尺寸整体缩放 |

变换规则：

- 一次连续拖动只生成一个撤销记录。
- 拖动过程中只更新内存与视觉树，完成后批量持久化，不能每帧写 SQLite。
- 图片最小可见边保持可操作；极端缩小后仍能通过透明命中区重新选中。
- 裁剪是独立模式，不能用拉伸代替裁剪。
- 重置变换恢复图片初始比例、旋转和尺寸，但不清除用户明确保存的画板位置。
- 多选包含不支持某种变换的对象时，菜单必须禁用该命令并给出原因，不能部分静默执行。

### 2.4 右键和窗口拖动

- 右键按下时记录位置和窗口状态。
- 移动不超过 6 DIP 且松开：在松开点打开上下文菜单。
- 移动超过 6 DIP：取消菜单候选。
- 窗口化时右键拖动移动整个无边框画板窗口。
- 最大化时右键拖动平移画布，不把最大化窗口拖离屏幕。
- 右键命中图片、便签、选择外框、空白画布和顶部栏时使用不同上下文。
- 右键拖动必须正确处理多显示器、负屏幕坐标和每显示器 DPI。

### 2.5 隐藏顶部栏与窗口置顶

顶部栏默认隐藏并覆盖在画布之上，不参与画布测量。建议内容：

1. 当前画板名称与切换。
2. 新建画板。
3. 撤销、重做。
4. 聚焦完整画板。
5. 当前缩放比例。
6. **窗口置顶按钮**。
7. 最小化、最大化/还原、关闭。

置顶规则：

- 按钮控制当前画板窗口的 `Topmost`。
- 默认关闭。
- 状态写入应用设置，不写入画板内容表。
- 快捷键为 `Ctrl+Shift+A`，右键菜单入口为“窗口 > 保持置顶”。
- 开启时按钮显示明确选中态，并出现“画板已置顶”轻提示；关闭时提示“已取消置顶”。
- 置顶不等于顶部栏常显；鼠标离开后顶部栏仍自动隐藏。
- 多画板窗口共享默认偏好，但每个已打开窗口必须立即同步实际状态。

顶部栏显隐：

- 指针进入顶部约 8 DIP 激活带并按现有边缘意图规则停留约 90–140ms 后显示。
- 显示后使用安全走廊，允许指针从边缘进入按钮区域。
- 指针离开且没有菜单、下拉、键盘焦点或窗口拖动时自动隐藏。
- `Alt` 或 `F10` 可从键盘临时显示并聚焦顶部栏。
- 减少动效模式下保留意图时序，但显隐动画时长为 0。

### 2.6 临时检查器

- 默认关闭，不永久占用右侧宽度。
- 按 `I`、右键“属性”或顶部栏明确入口打开。
- 以覆盖浮层出现，不改变 `BoardViewport` 实际尺寸，不触发画板重排。
- 单选图片时显示尺寸、比例、旋转、裁剪、分组、源文件状态和重新定位入口。
- 多选时显示数量、共同分组和可批量执行的层级/变换命令。
- 便签时显示颜色、尺寸和删除入口；文本继续在便签本体编辑。
- 单击画布空白、按 `I`、按 `Esc` 或完成不需要持续展示的操作后关闭。
- 检查器内部具有键盘焦点或存在未完成输入时，不因鼠标短暂离开自动关闭。

### 2.7 上下文菜单结构

画布空白：

- 撤销 / 重做
- 粘贴
- 新建便签
- 显示全部
- 恢复 100%
- 画板：切换、新建、重命名、删除、背景
- 窗口：置顶、最大化/还原、显示顶部栏、属性
- 设置 / 快捷键说明

图片或多选：

- 聚焦所选
- 打开原图
- 复制
- 变换：重置尺寸、旋转、翻转（实现前若无数据语义则不提前加入）
- 裁剪 / 重置裁剪
- 层级：移到最前、前移、后移、移到最后
- 分组 / 取消分组 / 重命名分组
- 重新定位缺失原图
- 属性
- 从画板移除

便签：

- 编辑文本
- 切换颜色
- 层级
- 属性
- 删除便签

安全文案：

- 图片命令必须写“从画板移除”，不能写模糊的“删除图片”。
- 删除画板必须提示“不会删除图库图片”。
- 粘贴任意外部图片时必须先走现有受管收录/导入边界；不能把不可追踪的临时绝对路径直接写入画板。

### 3.2 建议新增或拆分

- `BoardWindow.Camera.cs`：相机、聚焦会话、动画和持久化边界。

- `BoardWindow.Commands.cs`：统一命令、快捷键与可执行状态。
- `BoardWindow.ContextMenus.cs`：按目标动态构造右键菜单。
- `BoardWindow.Chrome.cs`：无边框窗口、隐藏顶部栏、置顶和窗口按钮。

- 不为追求架构纯度一次重写全部 `BoardWindow`。

- 所有命令必须只有一个真实执行入口；顶部栏、右键和快捷键只负责调用。

### 3.3 数据模型原则

- 聚焦状态、顶部栏开合、上下文菜单和临时检查器均为窗口临时状态，不进入画板数据库。
- 画板工作相机继续写 `boards` 既有视口字段。
- `BoardAlwaysOnTop` 属于应用设置，默认 `false`。
- 图片等比/自由变形继续使用现有 Width/Height；无需仅为 M8 增加 schema。
- 如果实现过程中发现必须增加不可重建用户字段，必须先在总蓝图增加决策记录并走升级前备份与迁移测试。
- 不为尚未确认的绘画对象预建数据库表；命令和选择目标只需避免封死未来扩展。

### 4.1 数据安全

- 重新定位只更新画板项覆盖路径，不静默改写图库资产事实。
- 任意测试删除前必须确认目标位于明确的工作区隔离根。

### 4.2 性能和画面连续性

## 8. 推荐验证命令与隔离要求

在仓库根目录执行：

```powershell
$env:APPDATA=(Resolve-Path '.').Path+'\.appdata'
$env:LOCALAPPDATA=(Resolve-Path '.').Path+'\.localappdata'
$env:DOTNET_CLI_HOME=(Resolve-Path '.').Path+'\.dotnethome'
$env:NUGET_PACKAGES=(Resolve-Path '.').Path+'\.packages'
```

按顺序执行，避免共享 `obj` 并发冲突：

```powershell
& '.\.dotnet\dotnet.exe' build src\PromptVault.App\PromptVault.App.csproj -c Debug --no-restore
& '.\.dotnet\dotnet.exe' test tests\PromptVault.Tests\PromptVault.Tests.csproj -c Debug --no-restore
& '.\.dotnet\dotnet.exe' build tools\PromptVault.M5BoardProbe\PromptVault.M5BoardProbe.csproj -c Release --no-restore
```

M8 已建立 `PromptVault.M8Gate` 聚合门禁；它汇总 M8 相机、输入、命令、窗口、检查器、变换、渐进高清以及 M5/M7.2 回归证据。Release 收口命令为：

```powershell
& '.\.dotnet\dotnet.exe' run --project tools\PromptVault.M8Gate\PromptVault.M8Gate.csproj -c Release --no-build -- --output 'docs\performance\2026-08-01-m8-pureref-board-gate.json' --camera '<camera-report>' --input '<input-report>' --command '<command-report>' --chrome '<chrome-report>' --inspector '<inspector-report>' --transform '<transform-report>' --image '<image-report>' --m5 '<m5-report>' --m7 '<m7.2-report>'
```

所有主窗口运行必须类似：

```powershell
& '<PromptVault.exe>' --settings '<工作区隔离设置绝对路径>'
```

启动前必须人工或脚本核对：

- `LibraryRoot` 位于工作区合成目录。
- `CaptureListeningEnabled=false`。
- `CaptureQuickEditEnabled=false`。
- `OnlineAiEnabled=false`。
- 设置路径加引号。
- 测试窗口标题或诊断事件能确认正在使用目标设置。
