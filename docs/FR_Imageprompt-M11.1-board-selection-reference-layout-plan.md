# M11.1 画板选择、顶部栏、参考锁定与多图排版

状态：实施中。日期：2026-09-08。基线：M11 `a1f0733`（已提交、推送，403 项测试）。

## 已确认范围与行为

用户要求四项一起实施：全选包含便签；Alt+Q 唤出顶部栏不再快速收回；参考锁定；多图对齐与等间距排版。沿用既有无人值守实施、验证、发布及提交推送授权。

- 全选及框选包含图片和便签；文字编辑中的 Ctrl+A 仍由文本框处理。点住已选图片或便签保留整个选择集，混合选择可共同移动、删除及一步撤销。混合选择显示共同轮廓和成员轮廓；尺寸编辑仍使用各类型现有手柄，不为混合选择增加缩放/旋转职责。
- Alt+Q 忽略长按重复事件，主动打开后保持显示，直到再次 Alt+Q 或在画布按下鼠标。按用户本轮补充，鼠标顶部感应区改为连续悬停 450ms 才唤出；离开立即取消，快速划过及拖动不唤出。鼠标唤出仍采用 500ms 安全隐藏；焦点、弹层、菜单交互期间不隐藏。切换动画中也不遗留隐藏计时器。
- 参考锁定保护当前画板的图片和便签：禁止移动、尺寸、旋转、裁剪、内容/样式修改、增删、排版、撤销/重做以及删除当前画板。允许选择、复制图片、打开原图、缩放、平移、临时聚焦、窗口操作、切换和新建画板。提供顶部开关、右键入口、Ctrl+L 和常驻小标识。按图库路径与画板 ID 记忆到应用设置，默认关闭，不增加数据库 schema。
- 开启锁定前结束并保存文字/样式编辑、取消未完成指针预览并处理裁剪；保存失败时保留编辑态和待保存内容，不谎报锁定成功。已锁定的画板重新打开继续保护。
- 排版入口位于右键“图片排版”：左/水平居中/右/顶部/垂直居中/底部对齐（至少两张），横向/纵向等间距（至少三张）。仅移动所选图片，便签不参与，保留图片尺寸、旋转、裁剪与分组。按旋转后可见矩形外包围框计算；等间距保持两端锚点，空间不足时提示而不制造重叠。排序相同位置以 ID 决定，结果稳定。
- 每次有效排版一次批量写入和一个历史快照；无变化不写入、不增加撤销。失败保留 M11 待保存重试语义，未选对象和图库原图不变。
