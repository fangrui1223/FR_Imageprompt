# FR_Imageprompt V2.0 M9 发布说明

## 本次新增

- 增加完全离线的一机一证授权，无需账号、服务器或联网。
- 首次启动显示匿名设备请求码；导入有效 `.frlicense` 后立即进入程序。
- 支持默认永久许可证和可选一年许可证。
- V2 许可证覆盖当前及后续全部 V2.x 版本；V3 授权另行决定。
- 无证、损坏、篡改、错设备、过期、错产品或错版本时，在读取设置和打开图库之前完全拒绝。
- 提供独立授权人签发器 `FR_LicenseManager.exe`；它不会进入普通用户体验包。
- 签发私钥存入授权人 Windows 凭据管理器，并支持口令派生密钥与认证加密的备份/恢复。

## 用户授权流程

1. 用户解压并启动 `FR_Imageprompt.exe`。
2. 用户复制窗口中的 `FR2-...` 请求码并发送给授权人。
3. 授权人用私有签发器填写使用人、请求码和期限，生成 `.frlicense`。
4. 用户点击“导入许可证”；成功后同一进程进入程序。

许可证绑定电脑，不绑定程序目录或图库。移动程序、重新解压、切换图库和更新 V2.x 不需要重签；Windows 重装、系统盘更换或请求码改变时需要重新签发。

## 已知边界

- 离线永久许可证不能远程撤销，也不能阻止获得授权的人复制程序文件；它阻止的是未获得对应设备许可证的副本运行。
- 本方案不提供在线设备席位、远程禁用、自动续费或授权后台。若未来需要这些能力，应新建在线授权阶段，不能把网络依赖静默加入 M9。
- 私钥丢失不影响已经签发的许可证，但会失去继续签发能力，因此授权人必须保留加密备份和备份口令。

## 数据与性能

许可证验证只在进程启动时执行一次，不进入瀑布流、缩略图、滚动、搜索、AI 或画板热路径。请求码不包含图片、提示词、图库路径、用户名、账号、MAC 地址或网络数据；验证过程不发起网络请求。M7.2 极速浏览与 M8 画板行为保持不变。
