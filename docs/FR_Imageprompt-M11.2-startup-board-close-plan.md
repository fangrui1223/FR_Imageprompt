# M11.2 首屏布局与画板关闭稳定性修复

日期：2026-09-08。状态：实施中。基线：M11.1 源码 `f471059`，文档 `4c856b6`，均已推送。用户安装目录的发布清单和 EXE 哈希与 M11.1 一致。

## 问题与修复契约

1. 打开图库瞬间，图片有移位或轻微缩小。初步定位：首批内容布局使用空列表视口宽度，内容出现滚动条后，全量薄元数据应用再次取宽，可能造成两次尺寸不同。先用合成图库记录首批提交、实际渲染与后台索引提交的卡片位置/尺寸及视口宽度，验证根因后修复。首屏出现后，在用户未改变窗口/布局前，已有图片尺寸与位置必须保持稳定；保留右边缘安全区、全部薄元数据、受控位图缓存与虚拟化。
2. 打开画板、关闭画板、再点击主界面时闪退。真实日志两次记录 `CurrentChromePointerPosition → IsPointerInsideTopSafeCorridor → BoardTopHideTimerTick` 的 PresentationSource 未连接异常。窗口关闭后迟到的离开事件可重新启动计时器；需建立不可重新激活的关闭状态，在实际批准关闭后解除定时器回调，所有延时/原生鼠标入口检查窗口生命周期，坐标转换仅在视觉源有效时执行。保存失败取消关闭时仍须可继续操作。

保留 450ms 连续悬停、500ms 安全隐藏、Alt+Q 保持、原生缩放边缘与画板数据安全关闭。修复不变更数据库 schema，不修改用户原图或便签内容。
