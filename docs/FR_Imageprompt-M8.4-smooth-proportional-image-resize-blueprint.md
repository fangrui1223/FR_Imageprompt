## 1. 根因与产品契约

- [x] **M8.4-01-01** 记录真实反馈：小图普通等比缩放基本正常，正常尺寸/大图会闪烁、突然放大或缩小；Shift+拖角自由拉伸正常。
- [x] **M8.4-01-02** 定位根因：等比缩放每帧改变手柄自身位置，而旧实现累加 `Thumb.DragDelta` 的相对手柄位移，导致下一帧输入被手柄回移污染并产生反馈振荡；图片越大越明显。
- [x] **M8.4-01-03** 定位次要性能源：拖动每帧调用完整 `RenderVisibleItems()`，会扫描全画板、更新全部可见图片和便签；在大画板中增加延迟并放大视觉跳变。
- [x] **M8.4-01-04** 普通拖角必须以按下点到当前鼠标点的绝对屏幕位移计算，尺寸不得依赖前一帧手柄位置。
- [x] **M8.4-01-05** 拖动期间只更新冻结选择集中的图片几何和选择框，不重新查询/重建全部画板视觉，不写数据库。
- [x] **M8.4-01-06** 松手时只创建一个撤销记录、保存一次，并复用当前图片位图；不得因完成缩放重新创建图片视觉造成尾帧闪烁。
- [x] **M8.4-01-07** 普通、Alt、旋转图片、组合/多选都使用稳定绝对位移；Shift 与 Shift+Alt 语义保持不变。
