# 本地与在线 AI 隐私

## 默认本地行为

FR_Imageprompt 默认不启用在线 AI。本地 CLIP 模型、相似度索引、SQLite 数据库、缩略图和自由画板都在用户选择的图库内工作。DirectML 不可用时自动回退 CPU，不会因此改用网络服务。

本地模型的输出只是候选草稿。用户确认、修改或手工录入的数据具有永久优先级，后续模型重跑不会覆盖。

## 启用在线 AI 后发送什么

只有用户在“AI 设置”中明确启用并配置兼容 Chat Completions 的 HTTPS 端点后才会调用网络服务。一次视觉分析可能发送：

- 当前图片的原始像素内容；
- 可用分类名称和需要生成的元数据字段；
- 仅在“包含现有提示词”开关打开时发送当前提示词。

不会发送本机路径、备注、既有标签、SQLite 数据库、其他图库图片或诊断日志。服务提供方仍会收到网络地址，并按其自己的条款处理请求；启用前应阅读该服务的隐私政策。

## 密钥与日志

API 密钥只写入 Windows 凭据管理器，不进入 `settings.json`、数据库、日志、诊断包或仓库。普通日志在写入前会按字段名和文本模式脱敏；图片字段、提示词字段、令牌、密钥、凭据和完整路径会被移除或缩减。

在线调用失败不会阻断本地收录、浏览或本地 AI。关闭在线 AI 后不会再创建新的在线作业；已有队列状态仍保留用于审计。
